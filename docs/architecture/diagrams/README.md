## Diagram Types

All diagrams use Mermaid syntax and include:
- **Architecture Diagrams**: System structure and components
- **Sequence Diagrams**: Time-based interactions
- **Flow Charts**: Process and decision flows
- **State Diagrams**: State machines and transitions
- **Class Diagrams**: Object relationships

## Viewing Diagrams

These diagrams are rendered using Mermaid and can be viewed:
- Directly in GitHub
- In any Markdown viewer with Mermaid support
- Using online Mermaid editors
- In documentation generated by MkDocs/Sphinx

## Key Visual Elements

- **Components**: Major system parts
- **Relationships**: How components interact
- **Data Flow**: How information moves
- **State Changes**: System state transitions
